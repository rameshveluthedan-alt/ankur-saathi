# Teacher's lines as instructions: what changed in the six recorded plans (15 Nov 2026)

**For Vaishnavi.** The user found the paired forms ("लिखता/लिखती हूँ", "बोलूँगा/बोलूँगी") slow to read in a busy classroom. The app now writes the teacher's lines as short polite instructions, as NCERT's teacher notes do ("बोर्ड पर लिखें", "बच्चों से पूछें", "हर वाक्य दो बार बोलें").

- **New plans:** the AI is told to write this way, and the code converts any first person it still writes (`prompts/hindi_style.py`, `teacher_instructions`).
- **Quoted words are never changed:** what is said to the children, a dictation sentence, a letter.
- **The section headings** are now मैं करूँ · हम करें · तुम करो (before: मैं करूँगा · हम करेंगे · तुम करोगे, masculine only).
- **The six signed plans** below were converted by the same code, plus four lines by hand (under "By hand"; they apply on top of the After line shown for that field). Please read the AFTER lines and say if any reads wrongly.
